Em resumo

Cada nota de soberania digital (de A a E) com a justificação completa: pontuação em 100, critérios, níveis, fontes consultadas e histórico da nota.

  • Sem chave, sem registo: basta um simples pedido HTTP.
  • Respostas em JSON, textos em francês, inglês, alemão, espanhol, italiano, neerlandês, polaco ou português.
  • Dados com licença CC BY 4.0 : reutilização livre, incluindo comercial, com atribuição.
  • Pode ser chamada a partir de um servidor ou de uma página web.

URL base: https://api.trusti-score.eu/api/v1

Primeiro pedido

Aplicações com nota A ou B, 20 por página:

curl "https://api.trusti-score.eu/api/v1/apps?grade=A,B&per_page=20"

A avaliação detalhada de uma aplicação:

curl "https://api.trusti-score.eu/api/v1/apps/signal/assessment?lang=en"

O que podes consultar

RotaConteúdo
/appsLista paginada. Filtros: grade=A,B, category, q (nome), updated_since=YYYY-MM-DD, page, per_page (máximo 100).
/apps/{id}A ficha de uma aplicação: nota, editor, jurisdição, licença, ligações.
/apps/{id}/assessmentDetalhe da nota: pontuação, critérios, justificação, fontes, histórico.
/apps/{id}/alternativesAlternativas mais bem avaliadas.
/grade-changes?since=Mudanças de nota recentes.
/categoriesCategorias e número de aplicações.
/exportTodo o catálogo com os detalhes, num único ficheiro.

Acrescenta lang=pt ou lang=en para obter os textos traduzidos.

Exemplo de resposta

Cada resposta contém os dados (data) e a licença a respeitar (meta):

{
  "data": [
    {
      "id": "signal",
      "name": "Signal",
      "grade": "A",
      "category": "Messagerie",
      "isOpenSource": true,
      "assessment": { "score": 82, "assessedAt": "2026-11-01" },
      "trustiUrl": "https://app.trusti-score.eu/?app=signal"
    }
  ],
  "meta": {
    "license": "CC-BY-4.0",
    "attribution": "Source : TrustiScore (https://trusti-score.eu)",
    "pagination": { "page": 1, "perPage": 20, "total": 205 }
  }
}

Limites de utilização

  • 60 pedidos por minuto por endereço IP.
  • 20 exportações completas por hora: para uma cópia local, basta uma exportação e depois updated_since uma vez por dia.
  • Acima disso, a API responde 429 com um cabeçalho Retry-After (segundos de espera).

Precisas de mais para um projeto sério? Escreve-nos: uma chave dedicada dá uma quota mais alta.

Licença e atribuição

Os dados são publicados com a licença Creative Commons Atribuição 4.0. Podes copiá-los, transformá-los e usá-los comercialmente com uma condição: citar a fonte, de forma visível, junto às notas que mostras.

Por exemplo:

<p>Source: TrustiScore (<a href="https://trusti-score.eu">trusti-score.eu</a>), CC BY 4.0</p>

Documentação técnica

A especificação completa (OpenAPI 3.1) descreve cada campo e cada erro: openapi.json. Importa-a no Postman, no Insomnia ou num gerador de clientes.

Compromisso de estabilidade: na versão 1, nenhum campo é removido ou renomeado. Podem surgir novos campos.
