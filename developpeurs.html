En bref

Toutes les notes de souveraineté numérique (A à E) et leur justification complète : score sur 100, critères, niveaux, sources consultées et historique des notes.

  • Sans clé ni inscription : un simple appel HTTP suffit.
  • Réponses en JSON, textes en français, anglais ou allemand.
  • Données sous licence CC BY 4.0 : réutilisation libre, même commerciale, avec attribution.
  • Appelable depuis un serveur comme depuis une page web.

Adresse de base : https://api.trusti-score.eu/api/v1

Premier appel

Les applications notées A ou B, 20 par page :

curl "https://api.trusti-score.eu/api/v1/apps?grade=A,B&per_page=20"

Le détail de l'évaluation d'une application :

curl "https://api.trusti-score.eu/api/v1/apps/signal/assessment?lang=fr"

Ce que vous pouvez lire

RouteContenu
/appsListe paginée. Filtres : grade=A,B, category, q (nom), updated_since=AAAA-MM-JJ, page, per_page (100 au plus).
/apps/{id}Fiche d'une application : note, éditeur, juridiction, licence, liens.
/apps/{id}/assessmentDétail de la note : score, critères, justification, sources, historique.
/apps/{id}/alternativesAlternatives mieux notées.
/grade-changes?since=Changements de note récents.
/categoriesCatégories et nombre d'applications.
/exportTout le catalogue avec les détails, en un seul fichier.

Ajoutez lang=en ou lang=de pour les textes traduits.

Exemple de réponse

Chaque réponse contient les données (data) et la licence à respecter (meta) :

{
  "data": [
    {
      "id": "signal",
      "name": "Signal",
      "grade": "A",
      "category": "Messagerie",
      "isOpenSource": true,
      "assessment": { "score": 82, "assessedAt": "2026-11-01" },
      "trustiUrl": "https://app.trusti-score.eu/?app=signal"
    }
  ],
  "meta": {
    "license": "CC-BY-4.0",
    "attribution": "Source : TrustiScore (https://trusti-score.eu)",
    "pagination": { "page": 1, "perPage": 20, "total": 205 }
  }
}

Limites d'usage

  • 60 requêtes par minute et par adresse IP.
  • 20 exports complets par heure : pour une copie locale, un export puis updated_since chaque jour suffisent.
  • Au-delà, l'API répond 429 avec l'en-tête Retry-After (secondes à attendre).

Besoin de plus pour un projet sérieux ? Écrivez-nous : une clé dédiée donne un quota plus élevé.

Licence et attribution

Les données sont publiées sous licence Creative Commons Attribution 4.0. Vous pouvez les copier, les transformer et les utiliser commercialement, à une condition : citer la source, de façon visible, près des notes affichées.

Par exemple :

<p>Source : TrustiScore (<a href="https://trusti-score.eu">trusti-score.eu</a>), CC BY 4.0</p>

Documentation technique

La spécification complète (OpenAPI 3.1) décrit chaque champ et chaque erreur : openapi.json. Elle s'importe dans Postman, Insomnia ou un générateur de client.

Engagement de stabilité : en version 1, aucun champ n'est retiré ni renommé. De nouveaux champs peuvent apparaître.
