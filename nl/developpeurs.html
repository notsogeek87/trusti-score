In het kort

Elke score voor digitale soevereiniteit (A tot E) met de volledige motivering: score op 100, criteria, niveaus, geraadpleegde bronnen en geschiedenis van de score.

  • Geen sleutel, geen registratie: een gewone HTTP-oproep volstaat.
  • Antwoorden in JSON, teksten in het Frans, Engels, Duits, Spaans, Italiaans, Nederlands, Pools of Portugees.
  • Gegevens onder de licentie CC BY 4.0 : vrij hergebruik, ook commercieel, met bronvermelding.
  • Aan te roepen vanaf een server of vanuit een webpagina.

Basis-URL: https://api.trusti-score.eu/api/v1

Eerste oproep

Apps met score A of B, 20 per pagina:

curl "https://api.trusti-score.eu/api/v1/apps?grade=A,B&per_page=20"

De gedetailleerde beoordeling van een app:

curl "https://api.trusti-score.eu/api/v1/apps/signal/assessment?lang=en"

Wat je kunt opvragen

RouteInhoud
/appsLijst met paginering. Filters: grade=A,B, category, q (naam), updated_since=YYYY-MM-DD, page, per_page (max. 100).
/apps/{id}De fiche van een app: score, uitgever, jurisdictie, licentie, links.
/apps/{id}/assessmentDetails van de score: score, criteria, motivering, bronnen, geschiedenis.
/apps/{id}/alternativesBeter beoordeelde alternatieven.
/grade-changes?since=Recente scorewijzigingen.
/categoriesCategorieën en aantal apps.
/exportDe volledige catalogus met details, in één bestand.

Voeg lang=nl of lang=en toe voor vertaalde teksten.

Voorbeeldantwoord

Elk antwoord bevat de gegevens (data) en de licentie om te respecteren (meta):

{
  "data": [
    {
      "id": "signal",
      "name": "Signal",
      "grade": "A",
      "category": "Messagerie",
      "isOpenSource": true,
      "assessment": { "score": 82, "assessedAt": "2026-11-01" },
      "trustiUrl": "https://app.trusti-score.eu/?app=signal"
    }
  ],
  "meta": {
    "license": "CC-BY-4.0",
    "attribution": "Source : TrustiScore (https://trusti-score.eu)",
    "pagination": { "page": 1, "perPage": 20, "total": 205 }
  }
}

Gebruikslimieten

  • 60 verzoeken per minuut per IP-adres.
  • 20 volledige exports per uur: voor een lokale kopie volstaan één export en daarna updated_since eens per dag.
  • Daarboven geeft de API 429 met een Retry-After -header (aantal seconden wachten).

Meer nodig voor een serieus project? Schrijf ons: een eigen sleutel geeft een hoger quotum.

Licentie en bronvermelding

De gegevens worden gepubliceerd onder de licentie Creative Commons Naamsvermelding 4.0. Je mag ze kopiëren, bewerken en commercieel gebruiken, op één voorwaarde: vermeld de bron, zichtbaar, naast de scores die je toont.

<p>Source: TrustiScore (<a href="https://trusti-score.eu">trusti-score.eu</a>), CC BY 4.0</p>

Technische documentatie

De volledige specificatie (OpenAPI 3.1) beschrijft elk veld en elke fout: openapi.json. Importeer ze in Postman, Insomnia of een clientgenerator.

Stabiliteitsbelofte: in versie 1 wordt geen enkel veld verwijderd of hernoemd. Er kunnen nieuwe velden bijkomen.
