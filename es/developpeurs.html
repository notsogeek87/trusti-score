De un vistazo

Cada nota de soberanía digital (de la A a la E) con su justificación completa: puntuación sobre 100, criterios, niveles, fuentes consultadas e historial de la nota.

  • Sin clave ni registro: basta una simple llamada HTTP.
  • Respuestas en JSON, textos en francés, inglés, alemán, español, italiano, neerlandés, polaco o portugués.
  • Datos bajo licencia CC BY 4.0 : reutilización libre, también comercial, citando la fuente.
  • Se puede llamar desde un servidor o desde una página web.

URL base: https://api.trusti-score.eu/api/v1

Primera llamada

Aplicaciones con nota A o B, 20 por página:

curl "https://api.trusti-score.eu/api/v1/apps?grade=A,B&per_page=20"

La evaluación detallada de una aplicación:

curl "https://api.trusti-score.eu/api/v1/apps/signal/assessment?lang=en"

Qué puedes consultar

RutaContenido
/appsLista paginada. Filtros: grade=A,B, category, q (nombre), updated_since=YYYY-MM-DD, page, per_page (100 como máximo).
/apps/{id}La ficha de una aplicación: nota, editor, jurisdicción, licencia, enlaces.
/apps/{id}/assessmentDetalle de la nota: puntuación, criterios, justificación, fuentes, historial.
/apps/{id}/alternativesAlternativas mejor valoradas.
/grade-changes?since=Cambios de nota recientes.
/categoriesCategorías y número de aplicaciones.
/exportTodo el catálogo con sus detalles, en un único archivo.

Añade lang=es o lang=en para obtener los textos traducidos.

Ejemplo de respuesta

Cada respuesta contiene los datos (data) y la licencia que hay que respetar (meta):

{
  "data": [
    {
      "id": "signal",
      "name": "Signal",
      "grade": "A",
      "category": "Messagerie",
      "isOpenSource": true,
      "assessment": { "score": 82, "assessedAt": "2026-11-01" },
      "trustiUrl": "https://app.trusti-score.eu/?app=signal"
    }
  ],
  "meta": {
    "license": "CC-BY-4.0",
    "attribution": "Source : TrustiScore (https://trusti-score.eu)",
    "pagination": { "page": 1, "perPage": 20, "total": 205 }
  }
}

Límites de uso

  • 60 solicitudes por minuto por dirección IP.
  • 20 exportaciones completas por hora: para una copia local, basta con una exportación y luego updated_since una vez al día.
  • Por encima, la API responde 429 con una cabecera Retry-After (segundos que hay que esperar).

¿Necesitas más para un proyecto serio? Escríbenos: una clave dedicada da una cuota mayor.

Licencia y atribución

Los datos se publican bajo la licencia Creative Commons Atribución 4.0. Puedes copiarlos, transformarlos y usarlos comercialmente con una condición: citar la fuente, de forma visible, junto a las notas que muestres.

Por ejemplo:

<p>Source: TrustiScore (<a href="https://trusti-score.eu">trusti-score.eu</a>), CC BY 4.0</p>

Documentación técnica

La especificación completa (OpenAPI 3.1) describe cada campo y cada error: openapi.json. Impórtala en Postman, Insomnia o un generador de clientes.

Compromiso de estabilidad: en la versión 1 no se elimina ni se renombra ningún campo. Pueden aparecer campos nuevos.
