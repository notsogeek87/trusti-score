W skrócie

Każda ocena suwerenności cyfrowej (od A do E) z pełnym uzasadnieniem: wynik na 100, kryteria, poziomy, sprawdzone źródła i historia oceny.

  • Bez klucza, bez rejestracji: wystarczy zwykłe wywołanie HTTP.
  • Odpowiedzi w JSON, teksty po francusku, angielsku, niemiecku, hiszpańsku, włosku, niderlandzku, polsku lub portugalsku.
  • Dane na licencji CC BY 4.0 : swobodne wykorzystanie, także komercyjne, z podaniem źródła.
  • Można je wywołać z serwera lub ze strony internetowej.

Bazowy URL: https://api.trusti-score.eu/api/v1

Pierwsze wywołanie

Aplikacje z oceną A lub B, 20 na stronę:

curl "https://api.trusti-score.eu/api/v1/apps?grade=A,B&per_page=20"

Szczegółowa ocena aplikacji:

curl "https://api.trusti-score.eu/api/v1/apps/signal/assessment?lang=en"

Co można odczytać

ŚcieżkaZawartość
/appsLista ze stronicowaniem. Filtry: grade=A,B, category, q (nazwa), updated_since=YYYY-MM-DD, page, per_page (maks. 100).
/apps/{id}Karta aplikacji: ocena, wydawca, jurysdykcja, licencja, linki.
/apps/{id}/assessmentSzczegóły oceny: wynik, kryteria, uzasadnienie, źródła, historia.
/apps/{id}/alternativesLepiej ocenione alternatywy.
/grade-changes?since=Ostatnie zmiany ocen.
/categoriesKategorie i liczba aplikacji.
/exportCały katalog ze szczegółami w jednym pliku.

Dodaj lang=pl lub lang=en , aby otrzymać przetłumaczone teksty.

Przykładowa odpowiedź

Każda odpowiedź zawiera dane (data) i licencję do przestrzegania (meta):

{
  "data": [
    {
      "id": "signal",
      "name": "Signal",
      "grade": "A",
      "category": "Messagerie",
      "isOpenSource": true,
      "assessment": { "score": 82, "assessedAt": "2026-11-01" },
      "trustiUrl": "https://app.trusti-score.eu/?app=signal"
    }
  ],
  "meta": {
    "license": "CC-BY-4.0",
    "attribution": "Source : TrustiScore (https://trusti-score.eu)",
    "pagination": { "page": 1, "perPage": 20, "total": 205 }
  }
}

Limity użycia

  • 60 zapytań na minutę na adres IP.
  • 20 pełnych eksportów na godzinę: do lokalnej kopii wystarczy jeden eksport, a potem updated_since raz dziennie.
  • Powyżej tego limitu API zwraca 429 z nagłówkiem Retry-After (liczba sekund oczekiwania).

Potrzebujesz więcej do poważnego projektu? Napisz do nas: dedykowany klucz daje wyższy limit.

Licencja i uznanie autorstwa

Dane są publikowane na licencji Creative Commons Uznanie autorstwa 4.0. Możesz je kopiować, przetwarzać i wykorzystywać komercyjnie pod jednym warunkiem: podaj źródło, w widoczny sposób, obok wyświetlanych ocen.

Na przykład:

<p>Source: TrustiScore (<a href="https://trusti-score.eu">trusti-score.eu</a>), CC BY 4.0</p>

Dokumentacja techniczna

Pełna specyfikacja (OpenAPI 3.1) opisuje każde pole i każdy błąd: openapi.json. Zaimportuj ją do Postmana, Insomnii lub generatora klientów.

Zobowiązanie stabilności: w wersji 1 żadne pole nie zostanie usunięte ani przemianowane. Mogą pojawić się nowe pola.
