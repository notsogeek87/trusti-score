Auf einen Blick

Alle Noten zur digitalen Souveränität (A bis E) mit vollständiger Begründung: Punktzahl von 100, Kriterien, Stufen, geprüfte Quellen und Notenverlauf.

  • Ohne Schlüssel, ohne Anmeldung: ein einfacher HTTP-Aufruf genügt.
  • Antworten in JSON, Texte auf Französisch, Englisch oder Deutsch.
  • Daten unter der Lizenz CC BY 4.0: freie Weiterverwendung, auch kommerziell, mit Quellenangabe.
  • Aufrufbar von einem Server oder einer Webseite.

Basis-URL: https://api.trusti-score.eu/api/v1

Erster Aufruf

Apps mit Note A oder B, 20 pro Seite:

curl "https://api.trusti-score.eu/api/v1/apps?grade=A,B&per_page=20"

Die detaillierte Bewertung einer App:

curl "https://api.trusti-score.eu/api/v1/apps/signal/assessment?lang=de"

Was Sie lesen können

RouteInhalt
/appsSeitenweise Liste. Filter: grade=A,B, category, q (Name), updated_since=JJJJ-MM-TT, page, per_page (höchstens 100).
/apps/{id}Steckbrief einer App: Note, Anbieter, Rechtsraum, Lizenz, Links.
/apps/{id}/assessmentDetails der Note: Punktzahl, Kriterien, Begründung, Quellen, Verlauf.
/apps/{id}/alternativesBesser bewertete Alternativen.
/grade-changes?since=Neue Notenänderungen.
/categoriesKategorien und Anzahl der Apps.
/exportDer gesamte Katalog mit Details, in einer einzigen Datei.

Fügen Sie lang=en oder lang=de für übersetzte Texte hinzu.

Beispielantwort

Jede Antwort enthält die Daten (data) und die einzuhaltende Lizenz (meta):

{
  "data": [
    {
      "id": "signal",
      "name": "Signal",
      "grade": "A",
      "category": "Messagerie",
      "isOpenSource": true,
      "assessment": { "score": 82, "assessedAt": "2026-11-01" },
      "trustiUrl": "https://app.trusti-score.eu/?app=signal"
    }
  ],
  "meta": {
    "license": "CC-BY-4.0",
    "attribution": "Source : TrustiScore (https://trusti-score.eu)",
    "pagination": { "page": 1, "perPage": 20, "total": 205 }
  }
}

Nutzungsgrenzen

  • 60 Anfragen pro Minute und IP-Adresse.
  • 20 vollständige Exporte pro Stunde: für eine lokale Kopie genügen ein Export und danach täglich updated_since.
  • Darüber hinaus antwortet die API mit 429 und dem Header Retry-After (Wartezeit in Sekunden).

Mehr nötig für ein ernsthaftes Projekt? Schreiben Sie uns: ein eigener Schlüssel gibt ein höheres Kontingent.

Lizenz und Quellenangabe

Die Daten stehen unter der Lizenz Creative Commons Namensnennung 4.0. Sie dürfen sie kopieren, verändern und kommerziell nutzen, unter einer Bedingung: die Quelle sichtbar neben den angezeigten Noten nennen.

Zum Beispiel:

<p>Quelle: TrustiScore (<a href="https://trusti-score.eu">trusti-score.eu</a>), CC BY 4.0</p>

Technische Dokumentation

Die vollständige Spezifikation (OpenAPI 3.1) beschreibt jedes Feld und jeden Fehler: openapi.json. Sie lässt sich in Postman, Insomnia oder einen Client-Generator importieren.

Stabilitätszusage: In Version 1 wird kein Feld entfernt oder umbenannt. Neue Felder können hinzukommen.
