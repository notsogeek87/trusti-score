At a glance

Every digital sovereignty grade (A to E) with its full justification: score out of 100, criteria, levels, sources consulted and grade history.

  • No key, no sign-up: a plain HTTP call is enough.
  • JSON responses, texts in French, English or German.
  • Data under the CC BY 4.0 licence: free reuse, including commercial, with attribution.
  • Callable from a server or from a web page.

Base URL: https://api.trusti-score.eu/api/v1

First call

Apps graded A or B, 20 per page:

curl "https://api.trusti-score.eu/api/v1/apps?grade=A,B&per_page=20"

The detailed assessment of an app:

curl "https://api.trusti-score.eu/api/v1/apps/signal/assessment?lang=en"

What you can read

RouteContent
/appsPaginated list. Filters: grade=A,B, category, q (name), updated_since=YYYY-MM-DD, page, per_page (100 max).
/apps/{id}An app's record: grade, publisher, jurisdiction, licence, links.
/apps/{id}/assessmentGrade details: score, criteria, rationale, sources, history.
/apps/{id}/alternativesBetter-graded alternatives.
/grade-changes?since=Recent grade changes.
/categoriesCategories and number of apps.
/exportThe whole catalogue with details, in a single file.

Add lang=en or lang=de for translated texts.

Sample response

Every response holds the data (data) and the licence to respect (meta):

{
  "data": [
    {
      "id": "signal",
      "name": "Signal",
      "grade": "A",
      "category": "Messagerie",
      "isOpenSource": true,
      "assessment": { "score": 82, "assessedAt": "2026-11-01" },
      "trustiUrl": "https://app.trusti-score.eu/?app=signal"
    }
  ],
  "meta": {
    "license": "CC-BY-4.0",
    "attribution": "Source : TrustiScore (https://trusti-score.eu)",
    "pagination": { "page": 1, "perPage": 20, "total": 205 }
  }
}

Usage limits

  • 60 requests per minute per IP address.
  • 20 full exports per hour: for a local copy, one export then updated_since once a day is enough.
  • Beyond that, the API returns 429 with a Retry-After header (seconds to wait).

Need more for a serious project? Write to us: a dedicated key gives a higher quota.

Licence and attribution

The data is published under the Creative Commons Attribution 4.0 licence. You may copy it, transform it and use it commercially, on one condition: credit the source, visibly, next to the grades you display.

For example:

<p>Source: TrustiScore (<a href="https://trusti-score.eu">trusti-score.eu</a>), CC BY 4.0</p>

Technical documentation

The full specification (OpenAPI 3.1) describes every field and every error: openapi.json. Import it into Postman, Insomnia or a client generator.

Stability commitment: in version 1, no field is removed or renamed. New fields may appear.
